*Taken from Google Scholar using "computational thinking"*

**Reference:**
Wing, J. M. (2006). Computational Thinking. Communications of the ACM. 49(3), 33-35.

**Key points:**
- Computational thinking is a fundamental skill of every person, and not only of computer scientists.
- It consists of problem solving through decomposition and focusing only on relevant aspects.
- Computer scientists solve problems by thinking about worst-case scenarios with the use of tools such as redundancy or error correction.

**How I used it:**
Example of a bug in a banking system. Programmers examine bugs in the system, compare possible solutions, and provide recovery means so the system can recover if problems appear.

*Taken from Google Scholar using "data cleaning"*

**Reference:**
Rahm, E. and Do, H. H. (2000). Data Cleaning: Problems and Current Approaches. IEEE Data Engineering Bulletin. 23(4), 3-13.

**Key points:**
- Data-related problems can be separated into single-source and multi-source.
- If the data came from many sources, it may contain duplicates, naming problems, and contradictions.
- Data cleaning is an important stage in ETL for the organization of data.

**How I used it:**
Example of Grab food delivery service. Order information comes from multiple sources, therefore, data engineers check and clean the information before working on charts.
